Forensic tools &
evidence identification

An introduction to OSForensics, FTK Imager and ProDiscover, with emphasis on identifying potential evidence, understanding hashes, and examining forensic disk images.

OSForensicsFTK ImagerHash setsRegistry ViewerProDiscover

01 Learning objectives

  • Understand how forensic software helps investigators locate potential digital evidence.
  • Explain what a file hash represents and how hashes support integrity checks.
  • Distinguish forensic imaging from working directly on original storage media.
  • Recognize the stated roles and limitations of the tools covered in the assignment.

02 Concepts explained

OSForensics

A forensic investigation tool used to locate and examine potential evidence. The assignment also covers hash sets, which can help identify known files associated with operating systems and applications.

File hash

A mathematical digest commonly represented as a hexadecimal value. Comparing hashes can help determine whether a file or forensic image has changed.

FTK Imager

A tool used to create forensic disk images for later examination. A bit-stream image allows analysis of a copy rather than repeatedly interacting with the original evidence.

Registry Viewer

The assignment highlights forensic information such as website-visit history that may be recovered from registry data using specialized viewing capabilities.

ProDiscover

The lab asks about supported file systems and the tool's role in examining digital evidence. The submitted answer identifies HFS+ as the exception in that question.

Evidence integrity

Hash verification and careful evidence handling support confidence that the material examined is consistent with the acquired evidence.

ASSIGNMENT 02DELETED FILES & RECOVERY

Deleted files &
data recovery

A study of what happens when files are deleted, how file-system metadata relates to deletion, and why recovery may be possible until data is overwritten.

Deleted filesMFTData carvingOverwritingSecure erasure

01 Learning objectives

  • Describe why deletion does not always mean immediate physical removal of file contents.
  • Understand the role of file-system metadata and the Master File Table (MFT).
  • Explain the basic idea of data carving and the effect of overwriting.
  • Distinguish ordinary deletion from secure data destruction.

02 Concepts explained

Logical deletion

Deleting a file commonly changes file-system records so that the space can be reused. Until that space is overwritten, some or all of the file's content may remain recoverable.

Master File Table (MFT)

In NTFS, the MFT stores metadata records about files and directories. Deletion affects the file-system's records and allocation status; it does not necessarily erase every underlying data byte immediately.

Data carving

A recovery approach that searches raw data for recognizable file structures or signatures, potentially rebuilding files when normal directory references are missing.

Overwriting

When new data is written over storage locations previously occupied by a deleted file, recovery of the overwritten content becomes difficult or impossible.

Secure destruction

The assignment describes overwriting as a method intended to prevent recovery of file remnants. The appropriate sanitization method depends on the storage technology and applicable standard.

Recovery limitations

Recovery depends on whether the relevant content remains intact, the file system, storage behavior, and whether subsequent activity has reused the space.

03 Submitted answer record

Can deleted files be rebuilt?

Submitted answer: Yes, from remnants that have not been overwritten.

When a file is deleted, is only its pointer removed?

Submitted answer: True.

How many wipes does the submitted answer attribute to NIST?

Submitted answer: Seven. Verification note: Treat this as the answer recorded in the coursework, not as a universal current NIST rule. The exact sanitization guidance should be checked against the specific NIST publication and storage type.

What happens to the MFT when files are deleted?

Submitted answer: The MFT is updated to indicate free space when files are deleted.

What does the assignment describe for secure data destruction?

Submitted answer: Writing zeros and ones to the storage device to overwrite file remnants.

What is the process of recovering deleted files that have not been overwritten?

Submitted answer: Data carving.

KEY TAKEAWAY

Deletion often changes the file system's references before the underlying content is overwritten. Preservation and timely forensic acquisition are therefore important when recovery may be required.

03DISK IMAGING
ASSIGNMENT 03IMAGES & WRITE PROTECTION

Disk images &
write-blockers

A study of forensic image contents, ProDiscover Basic, unallocated space, and the role of write-blockers in protecting original digital evidence.

ProDiscover BasicDisk imagesMFTUnallocated spaceWrite-blockers

01 Learning objectives

  • Understand why investigators acquire forensic images of storage devices.
  • Recognize the importance of preserving file-system metadata and unallocated space.
  • Explain how write-blockers reduce the risk of modifying original evidence.
  • Connect forensic imaging with evidence integrity and chain of custody.

02 Concepts explained

Forensic disk image

A sector-level or bit-stream copy intended to preserve the source media for examination. The image can include file-system structures and areas not currently allocated to active files.

Master File Table

The submitted ProDiscover question focuses on copying the MFT as part of the image. The MFT provides important file and directory metadata for an NTFS volume.

Unallocated space

Storage space not currently assigned to active files may still contain remnants of deleted data. Preserving it can support later examination and recovery attempts.

Write-blocker

A hardware or software control designed to prevent write operations to the original storage device during acquisition or examination, reducing the risk of evidence alteration.

Image formats

The assignment tests recognition of image formats supported by ProDiscover Basic. The submitted answer identifies .vhd as the exception in that multiple-choice question.

Chain of custody

A documented record of how evidence is collected, handled, transferred, stored and examined. Imaging and write protection support this process but do not replace documentation.

03 Submitted answer record

Which image format was the exception in the ProDiscover Basic question?

Submitted answer: .vhd.

Do disk images include the MFT?

Submitted answer: False — the statement that disk images do not include the MFT is false.

What does a ProDiscover Basic image copy, according to the assignment?

Submitted answer: The MFT and any unallocated free space from the original storage device.

What is the purpose of a write-blocker?

Submitted answer: Preventing data on the original storage device from being overwritten, which would violate the chain of custody.

What is the purpose of disk imaging?

Submitted answer: Maintaining the chain of custody.

KEY TAKEAWAY

Forensic imaging creates a working copy for examination, while write-blocking helps protect the original media. Both contribute to preserving the reliability of digital evidence.
